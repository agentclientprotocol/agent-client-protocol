**Published:** November 6, 2026

The [Client-Provided System Prompt RFD](/rfds/client-system-prompt) has moved to
Completed, stabilizing the `systemPrompt` field on session setup requests and
the `systemPrompt` session capability.

For protocol details, see [v1 Session Setup](/protocol/v1/session-setup#system-prompt)
and [v2 Session Setup](/protocol/v2/session-setup#system-prompt).
